# Почта любви для Александры

Интерактивное приглашение в кино: сова, письмо, три задания и два памятных билета.

**Когда:** суббота, 26 сентября 2026, 16:00.

## Публикация

Статический сайт без сборки. Для GitHub Pages используется ветка `main` и папка `/ (root)`. Все пути относительные; файл `.nojekyll` отключает обработку Jekyll.

## Музыка

Сайт больше не использует YouTube или внешний музыкальный плеер. Фоновая музыка подключается локально из файла:

`assets/background-music.mp3`

Сайт пытается запустить музыку при загрузке. Если браузер блокирует автозапуск со звуком, музыка запускается после первого касания страницы или открытия конверта.

## Файлы

- `index.html` — письмо, задания и билеты.
- `style.css` — оформление и адаптация для телефона.
- `app.js` — квест и сохранение билетов.
- `music.js` — локальная фоновая музыка и обработка запрета автозапуска.
- `assets/` — иллюстрации и локальный аудиофайл.
