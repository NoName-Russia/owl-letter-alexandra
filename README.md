# Совиная почта для Александры

Интерактивное приглашение в кино: сова, письмо, три задания и два памятных билета.

**Когда:** суббота, 26 сентября 2026, 16:00.

## Публикация

Статический сайт без сборки. Для GitHub Pages выберите ветку `main` и папку `/ (root)`. Все пути относительные; файл `.nojekyll` отключает обработку Jekyll.

## Музыка

Используется официальный YouTube-плеер Hedwig’s Theme. Сайт пытается включить звук при загрузке; если браузер блокирует автозапуск, попытка повторяется при открытии конверта. Кнопка музыки и пауза в плеере выключают звук. Выключение сохраняется при переходе между письмом, квестом и билетами.

YouTube должен быть доступен в сети посетителя. Музыкальный файл в репозитории не хранится.

## Файлы

- `index.html` — письмо, задания и билеты.
- `style.css` — оформление и адаптация для телефона.
- `app.js` — квест и сохранение билетов.
- `music.js` — музыка и обработка запрета автозапуска.
- `assets/` — оригинальные иллюстрации.
